# Foliokit Portfolio Starter - neourutalism

This is a high-fidelity portfolio template generated by [Foliokit](https://foliokit.com).

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. **Open the browser:**
   Go to [http://localhost:3000](http://localhost:3000) to see your portfolio.

## Customization

- **Content**: Update the `portfolioData` object in `app/page.tsx`.
- **Styling**: Modify `app/globals.css` or use Tailwind classes directly in components.
- **Components**: All components are located in the `components/` directory.

## Tech Stack

- **Framework**: Next.js 15+ (React 19)
- **Styling**: Tailwind CSS 4
- **Animations**: Framer Motion (via `motion/react`)
- **Icons**: Lucide React
